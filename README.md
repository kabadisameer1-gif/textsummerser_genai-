# 🤖 AI Document Assistant

An AI-powered chatbot built with **Python, Streamlit, and Google Gemini AI (GenAI)**. This project allows users to ask questions, get intelligent responses, summarize content, and interact with an AI assistant through a modern web interface.

---

## 🚀 Features

* 💬 AI chatbot interface
* 🧠 Powered by **Google Gemini AI**
* ⚡ Fast responses using **Gemini Flash**
* 📄 Document and text question answering
* 📝 Text summarization support
* 🌙 Clean dark-mode UI
* 🔐 Secure API key input from the sidebar

---

## 🛠️ Tech Stack

* **Python 3**
* **Streamlit**
* **Google Generative AI (Gemini API)**
* **python-dotenv**

## ⚙️ Installation

### 1. Clone the repository

```bash
git clone https://github.com/your-username/AI-Document-Assistant.git
cd AI-Document-Assistant
```

### 2. Create a virtual environment

```bash
python -m venv venv
```

### 3. Activate the environment

**Windows**

```bash
venv\Scripts\activate
```

**Linux / macOS**

```bash
source venv/bin/activate
```

### 4. Install dependencies

```bash
pip install -r requirements.txt
```

---

## 🔑 Setup Gemini API Key

Create a `.env` file in the project root:

```env
GOOGLE_API_KEY=YOUR_GEMINI_API_KEY
```

Get your free API key from **Google AI Studio**:
https://aistudio.google.com/

---

## ▶️ Run the App

```bash
streamlit run app.py
```

Open the browser at:

```text
http://localhost:8501
```

---

## 💡 Usage

1. Select a Gemini model from the sidebar.
2. Enter your Google Gemini API key.
3. Type a question in the input box.
4. Click **Generate Answer**.
5. Receive an AI-generated response instantly.
